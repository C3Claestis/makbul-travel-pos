# Nama Project

MAKBUL adalah platform Software-as-a-Service (SaaS) yang membantu pemilik travel umrah mengelola
seluruh proses bisnis secara terpusat dan terstruktur.
Platform ini dirancang untuk meningkatkan kenyamanan operasional, mengurangi kesalahan manual, dan
menciptakan pengalaman umrah yang lebih baik bagi jamaah.

## Features
- Login & Register
- SaaS setiap role
- Sinkronisasi Data
- Dashboard Monitoring

## Tech Stack
- Flutter
- Riverpod
- Firebase Auth
- Cloud Firestore
- Shared Preferences

## Project Structure

lib/
├── core/
├── features/
├── shared/
├── services/
└── main.dart

## Installation

### Clone Repository

git clone https://github.com/C3Claestis/makbul-travel-pos

### Install Dependency

flutter pub get

### Run Project

flutter run

## Build APK

flutter build apk --release

## Environment Configuration

Buat file .env belum ada configuration

## Architecture

Clean Architecture + Riverpod

Presentation
↓
Provider
↓
Repository
↓
Datasource
